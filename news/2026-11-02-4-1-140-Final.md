We are happy to announce the release of Netty 4.1.140.Final. This is a bug-fix and security release.

**Note that [Netty 4.1 will be End-of-Life on July 1st, 2027](https://netty.io/news/2026/09/09/4-1-EOL-announcement.html).**

We strongly recommend upgrading to this version to get the following security fixes:

- [CVE-2026-XXXXX](https://github.com/netty/netty/security/advisories/GHSA-m77g-r4c7-3w77) : out-of-bounds read in `netty-buffer`
- [CVE-2026-XXXXX](https://github.com/netty/netty/security/advisories/GHSA-rx4g-qxm6-238r) : out-of-bounds read in `netty-buffer`
- [CVE-2026-XXXXX](https://github.com/netty/netty/security/advisories/GHSA-cqmg-wc9g-fpj8) : insufficient entropy in `netty-resolver-dns`
- [CVE-2026-XXXXX](https://github.com/netty/netty/security/advisories/GHSA-hc9x-r52h-gh4x) : unbounded memory usage in `netty-codec-http2`
- [CVE-2026-XXXXX](https://github.com/netty/netty/security/advisories/GHSA-42mp-m8rq-6rgj) : insufficient control character neutralization in `netty-codec-http`
- [CVE-2026-XXXXX](https://github.com/netty/netty/security/advisories/GHSA-qhw9-p586-v948) : out-of-bounds read in `netty-buffer`
- [CVE-2026-XXXXX](https://github.com/netty/netty/security/advisories/GHSA-84gx-4cj4-rm7q) : unbounded memory usage in `netty-codec-mqtt`
- [CVE-2026-XXXXX](https://github.com/netty/netty/security/advisories/GHSA-6xv6-9mgg-mfvc) : mTLS auth bypass via session resumption in `netty-handler`

Other significant changes are:

* Reject Redis lines that start with LF [#17806](https://github.com/netty/netty/pull/17806)
* Do not let a negatively cached search domain shadow a positive one [#17805](https://github.com/netty/netty/pull/17805)
* Choose server key types from client's signature algorithms for TLS 1.3 [#17809](https://github.com/netty/netty/pull/17809)
* LocalChannel: Deliver data written by the peer before it closed [#17815](https://github.com/netty/netty/pull/17815)
* Validate padding of `HEADERS` frames without priority [#17819](https://github.com/netty/netty/pull/17819)
* Don't spin in `SslHandler.wrapMultiple(...)` when the engine consumes nothing [#17822](https://github.com/netty/netty/pull/17822)
* Preserve invalid SNI names in `ReferenceCountedOpenSslEngine` [#17824](https://github.com/netty/netty/pull/17824)
* Optimize redundant bounds checking in `ByteBuf.setBytes` [#17827](https://github.com/netty/netty/pull/17827)
* Release the DNS response when a query future loses a cancel race [#17828](https://github.com/netty/netty/pull/17828)
* Fix `HpackDynamicTable` losing entries when filled to capacity [#17846](https://github.com/netty/netty/pull/17846)
* Throw `UnsupportedOperationException` from `AdaptiveByteBuf.memoryAddress()` without an address [#17842](https://github.com/netty/netty/pull/17842)
* Handle `ed25519` and `ed448` names in `SignatureAlgorithmConverter` [#17850](https://github.com/netty/netty/pull/17850)
* HAProxyMessage: validate the length of all TLV types [#17845](https://github.com/netty/netty/pull/17845)
* Validate bzip2 Huffman code lengths before building decode tables [#17855](https://github.com/netty/netty/pull/17855)
* Validate header values on `DefaultHeaders.copy()`, bulk `add`, entry `setValue` and `ReadOnlyHttpHeaders` [#17854](https://github.com/netty/netty/pull/17854)
* Fix typos in comments/javadoc [#17863](https://github.com/netty/netty/pull/17863)
* HAProxyMessageEncoder: encode v1 `PROXY UNKNOWN` headers [#17860](https://github.com/netty/netty/pull/17860)
* Throw `DecompressionException` on `JdkZlib` preset dictionary mismatch [#17864](https://github.com/netty/netty/pull/17864)
* Apply certificate list size floor [#17861](https://github.com/netty/netty/pull/17861)
* Reject HTTP version numbers that overflow int [#17859](https://github.com/netty/netty/pull/17859)
* HAProxyMessage: decode TLVs with an empty value at the end of the header [#17877](https://github.com/netty/netty/pull/17877)
* Honor `maxAllocation` for brotli in `DelegatingDecompressorFrameListener` [#17881](https://github.com/netty/netty/pull/17881)
* Reject invalid content-length in `PUSH_PROMISE` with a stream error [#17875](https://github.com/netty/netty/pull/17875)
* HAProxyMessageDecoder: fix v2 header framing with a non-zero reader index [#17882](https://github.com/netty/netty/pull/17882)
* Skip JNDI nameserver lookup on IBM i [#17892](https://github.com/netty/netty/pull/17892)
* Reset the `h2c` upgrade stream if the request can not be converted [#17893](https://github.com/netty/netty/pull/17893)
* Fix NPE in `Http2FrameCodec` when `h2c` upgrade fails [#17899](https://github.com/netty/netty/pull/17899)
* Don't size `ZstdDecoder` output buffers from the frame content size [#17900](https://github.com/netty/netty/pull/17900)
* Don't lose frames when a delimiter is split across reads [#17909](https://github.com/netty/netty/pull/17909)
* Read SOCKS5 length octets unsigned in the legacy socks decoders [#17916](https://github.com/netty/netty/pull/17916)
* Fix truncated output in Brotli decoders [#17923](https://github.com/netty/netty/pull/17923)
* Port: Wrap trailing ';' in `Content-Disposition` as `ErrorDataDecoderException` [#17931](https://github.com/netty/netty/pull/17931)
* Kqueue: Deregister filters before closing the `fd` to avoid hitting a reused `fd` [#17939](https://github.com/netty/netty/pull/17939)
* Keep `WINDOW_UPDATE` credit of reserved HTTP/2 streams on activation [#17935](https://github.com/netty/netty/pull/17935)
* Accept empty non-final fragments in `PerMessageDeflateEncoder` [#17953](https://github.com/netty/netty/pull/17953)
* HTTP/2: Don't pass the close promise to a deferred close [#17959](https://github.com/netty/netty/pull/17959)
* Fix endless value iterators in `ReadOnlyHttpHeaders` [#17978](https://github.com/netty/netty/pull/17978)
* Don't drop the last character in `AsciiString.trim(CharSequence)` [#17993](https://github.com/netty/netty/pull/17993)
* Fix the region copied by `Unpooled.copiedBuffer(CharSequence, int, int, Charset)` [#17995](https://github.com/netty/netty/pull/17995)
* Add HpackDecoder test for non-token HTTP/2 header names [#17992](https://github.com/netty/netty/pull/17992)
* Fix `AsciiString.contains(...)` false negatives after a partial match [#17986](https://github.com/netty/netty/pull/17986)
* Treat DATA frames on reserved HTTP/2 streams as a connection error [#17998](https://github.com/netty/netty/pull/17998)
* Reject reply codes with non-digit characters in `SmtpResponseDecoder` [#18005](https://github.com/netty/netty/pull/18005)
* Don't loop forever in `AbstractDiskHttpData` when the file is short [#18004](https://github.com/netty/netty/pull/18004)
* Http2: reject generic frames whose payload exceeds `SETTINGS_MAX_FRAME_SIZE` [#18000](https://github.com/netty/netty/pull/18000)

* Check the second gzip magic byte in `JdkZlibDecoder` [#18007](https://github.com/netty/netty/pull/18007)
* Fix server-initiated WebSocket close handshake failing with "promise already done" [#18032](https://github.com/netty/netty/pull/18032)
* Fix `Snappy.encode(...)` for input with a non-zero reader index [#18031](https://github.com/netty/netty/pull/18031)
* MqttEncoder: Reject Variable Byte Integers larger than 268435455 [#18025](https://github.com/netty/netty/pull/18025)
* Only delete socket files when binding and closing UDS channels [#18044](https://github.com/netty/netty/pull/18044)
* Return the haystack's reader index from `ByteBufUtil.indexOf(...)` for an empty needle [#18082](https://github.com/netty/netty/pull/18082)

* Fail to encode DNS messages that are too large for TCP [#18081](https://github.com/netty/netty/pull/18081)
* Don't return an entry twice when removing while iterating a primitive map [#18087](https://github.com/netty/netty/pull/18087)
* Mark disk-based HttpData as completed after setting empty content [#18088](https://github.com/netty/netty/pull/18088)
* Fix out-of-bounds read when validating UDS paths in the native code [#18016](https://github.com/netty/netty/pull/18016)
* Release a SPDY `DATA` frame that exceeds the session window [#18094](https://github.com/netty/netty/pull/18094)
* Send zero-length datagrams instead of dropping or duplicating them [#18107](https://github.com/netty/netty/pull/18107)
* Reject request-only and response-only pseudo-headers in invalid contexts (RFC 9113) [#18113](https://github.com/netty/netty/pull/18113)
