We are happy to announce the release of Netty 4.1.141.Final. This is a bug-fix release.

**Note that [Netty 4.1 will be End-of-Life on July 1st, 2027](https://netty.io/news/2026/09/09/4-1-EOL-announcement.html).**

This release fixes a mistake in our build that affected Netty 4.2.20 and 4.1.140, where we accidentally increased the glibc version to 2.33 for x86_64 and aarch64.
In this release the glibc version requirements return to their previous versions.

Other significant changes are:

* Reject too long UDS paths in sendTo instead of truncating them [#18245](https://github.com/netty/netty/pull/18245)
* Don't invert `IP_MULTICAST_LOOP_DISABLED` in `NioDatagramChannelConfig` [#18243](https://github.com/netty/netty/pull/18243)
* Update Brotli4j version to 1.24.0 [#18247](https://github.com/netty/netty/pull/18247)
* Fix `FastLz.readU16` when the reader index is not 0 [#18246](https://github.com/netty/netty/pull/18246)
* Grow `KQueueEventArray` correctly in realloc [#18248](https://github.com/netty/netty/pull/18248)
* Complete the TCP fast open connect before notifying the initial write [#18244](https://github.com/netty/netty/pull/18244)
* Stop decoding in `Bzip2Decoder` after an error [#18261](https://github.com/netty/netty/pull/18261)
* NIO: Correctly catch all exceptions when `NioDatagramChannel.block(...)` fails [#18267](https://github.com/netty/netty/pull/18267)
* Only mirror 127.0.0.1 to the IPv6 loopback in `DnsQueryContextManager` [#18265](https://github.com/netty/netty/pull/18265)
* Upgrade lz4-java to 1.13.0 [#18280](https://github.com/netty/netty/pull/18280)
* Honour qvalues when `HttpContentCompressor` selects the content encoding [#18288](https://github.com/netty/netty/pull/18288)
* Use HTTP dates in `ReadOnlyHttp2Headers.containsTimeMillis` [#18287](https://github.com/netty/netty/pull/18287)
* Initialize the hexadecimal tables of `StringUtil` lazily and cheaply [#18292](https://github.com/netty/netty/pull/18292)
* Avoid `String.format` in `MacAddressUtil.formatAddress` [#18291](https://github.com/netty/netty/pull/18291)
* Use the configured directory when creating disk attributes [#18302](https://github.com/netty/netty/pull/18302)
* KQueue/Epoll: Fall back to buffered writes for non-`FileChannelImpl` channels [#18278](https://github.com/netty/netty/pull/18278)
* Encode the `char` after an unpaired high surrogate in `writeUtf8(...)` [#18307](https://github.com/netty/netty/pull/18307)
* Release the handshake response when a `WebSocket` extension is rejected [#18329](https://github.com/netty/netty/pull/18329)
* Notify `LeakListener` for every detected leak [#18334](https://github.com/netty/netty/pull/18334)
* Call `handshakeFailure` for failed TLS completion events [#18327](https://github.com/netty/netty/pull/18327)
* Check the range in `ByteBuf.toString(index, length, charset)` [#18340](https://github.com/netty/netty/pull/18340)
* Fail the `h2c` upgrade stream for all header conversion errors [#18346](https://github.com/netty/netty/pull/18346)
* Handle zero-length and invalid bulk reads in `ByteBufInputStream` [#18351](https://github.com/netty/netty/pull/18351)
* Avoid classloader leak via the shared `TransferEncodingNotAllowedException` [#18356](https://github.com/netty/netty/pull/18356)
* Avoid classloader leak via `ImmediateEventExecutor` `terminationFuture` failure [#18359](https://github.com/netty/netty/pull/18359)
* Fix `float` matching in read-only HTTP/2 headers [#18362](https://github.com/netty/netty/pull/18362)
* Call `handshakeFailure` for TLS timeouts and early closes [#18367](https://github.com/netty/netty/pull/18367)
* Keep adaptive buffer sizes within configured bounds [#18375](https://github.com/netty/netty/pull/18375)
* Canonicalize `NaN` values written [#18373](https://github.com/netty/netty/pull/18373)
* Reject all control characters and DEL in HTTP response reason phrases [#18381](https://github.com/netty/netty/pull/18381)
* Key per-channel traffic shaping state [#18386](https://github.com/netty/netty/pull/18386)
* Fix `ZstdDecoder` with a non-positive `defaultMaxForwardBytes` [#18401](https://github.com/netty/netty/pull/18401)
* Fix limit of bytes for gathering writes being ignored after the first buffer [#18396](https://github.com/netty/netty/pull/18396)
* Evict DNS cache entries when expiration tasks are cancelled [#18393](https://github.com/netty/netty/pull/18393)
* Resume `SslHandler` when the delegated task was consumed elsewhere [#18372](https://github.com/netty/netty/pull/18372)
* Fix `BrotliDecoder` with a non-positive `defaultMaxForwardBytes` [#18398](https://github.com/netty/netty/pull/18398)
* Don't stop reading domain datagrams after an empty datagram [#18395](https://github.com/netty/netty/pull/18395)
* Use the correct address length when sending batched datagrams to a domain socket [#18394](https://github.com/netty/netty/pull/18394)
* Fix accidental glibc version bump [#18390](https://github.com/netty/netty/pull/18390)
* Reject SPDY frames that do not fit the 24-bit length field [#18417](https://github.com/netty/netty/pull/18417)
* HAProxyMessageEncoder: Reject v2 headers longer than 65535 bytes [#18430](https://github.com/netty/netty/pull/18430)

For more details please see the [complete release notes](https://github.com/netty/netty/releases/tag/netty-4.1.141.Final).
