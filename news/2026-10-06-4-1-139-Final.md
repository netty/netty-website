We are happy to announce the release of Netty 4.1.139.Final. This is a bug-fix and security release.

**Note that [Netty 4.1 will be End-of-Life on July 1st, 2027](https://netty.io/news/2026/09/09/4-1-EOL-announcement.html).**

We strongly recommend upgrading to this version to get the following security fixes:

- [CVE-2026-XXXXX](https://github.com/netty/netty/security/advisories/GHSA-frq3-7pw6-36cg) : parser desync in `io.netty:netty-codec-haproxy`
- [CVE-2026-XXXXX](https://github.com/netty/netty/security/advisories/GHSA-6g26-xhvx-g5w3) : improper CRLF neutralization (request/response smuggling) in `io.netty:netty-codec-http`
- [CVE-2026-XXXXX](https://github.com/netty/netty/security/advisories/GHSA-x9f7-rg73-4rp6) : origin validation error in `io.netty:netty-codec-http`
- [CVE-2026-XXXXX](https://github.com/netty/netty/security/advisories/GHSA-2p3h-phr9-jf38) : unbounded resource consumption in `io.netty:netty-codec-http2`
- [CVE-2026-XXXXX](https://github.com/netty/netty/security/advisories/GHSA-vwgc-hvc9-2j59) : request/response smuggling in `io.netty:netty-codec-http`
- [CVE-2026-XXXXX](https://github.com/netty/netty/security/advisories/GHSA-m3w2-2657-46g8) : time-of-check/time-of-use error in `io.netty:netty-handler-ssl-ocsp`
- [CVE-2026-XXXXX](https://github.com/netty/netty/security/advisories/GHSA-jp47-57pp-4qpp) : SNI routing bypass in `io.netty:netty-handler`
- [CVE-2026-XXXXX](https://github.com/netty/netty/security/advisories/GHSA-35qr-v9mm-35c5) : unbounded resource consumption in `io.netty:netty-codec-xml`

- [CVE-2026-XXXXX](https://github.com/netty/netty/security/advisories/GHSA-x436-m93c-g2q9) : unbounded resource consumption in `io.netty:netty-codec-http`

Note that due to overwhelming strain on the CVE infrastructure, we have not gotten a single CVE number assigned to these reports in time for our release.
The advisories will be published without.

Specific changes worth calling out:

**Validation in `FileUpload.setContentType`.**
Previously, the `FileUpload.setContentType` methods did not validate their inputs.
They now throw an `IllegaalArgumentException` if the given string is not formatted as a plausible MIME content type.

Other significant changes are:

* Perf: Use `LinkedHashSet` to deduplicate search domains [#17407](https://github.com/netty/netty/pull/17407)
* Handle non-positive skip lengths in ByteBufInputStream [#17410](https://github.com/netty/netty/pull/17410)
* Protobuf: Update protobuf-javanano to non alpha release [#17335](https://github.com/netty/netty/pull/17335)
* `HttpUtil.getCharset()` must accept whitespace before the next `Content-Type` parameter [#17436](https://github.com/netty/netty/pull/17436)
* Codec-dns: Add `SMIMEA`, `CDS`, `CDNSKEY`, `OPENPGPKEY`, `CSYNC`, `ZONEMD` records [#17459](https://github.com/netty/netty/pull/17459)
* `HttpUtil.getMimeType()` must not include whitespace before the next `Content-Type` parameter [#17494](https://github.com/netty/netty/pull/17494)
* Fix buffer leak when `recvmmsg` returns single `UDP_GRO` batch [#17500](https://github.com/netty/netty/pull/17500)

* Reset `LengthFieldBasedFrameDecoder` state when the frame is shorter than `initialBytesToStrip` [#17621](https://github.com/netty/netty/pull/17621)
* Fix `ByteBuf.setBytes(int, ByteBuffer)` when the source is the buffer's own internal NIO buffer [#17626](https://github.com/netty/netty/pull/17626)
